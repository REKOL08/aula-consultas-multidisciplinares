# Aula · Consultas multidisciplinares

**[Abrir herramienta](https://rekol08.github.io/aula-consultas-multidisciplinares/)** · Sin cuentas ni instalaciones para visitantes.

Espacio de trabajo académico en español: consigna, rutas por disciplina, desarrollo, fichas de fuentes y revisión manual. Para estudiantes universitarios en Colombia y otros contextos hispanohablantes.

**Guía de trabajo, no respuesta generada ni validación experta.** Usa rutas predefinidas. No interpreta la pregunta, consulta una IA, resuelve ejercicios ni comprueba su corrección.

## Empezar
1. Elige una de siete áreas y escribe la consigna.
2. Sigue la ruta orientativa y adapta los pasos a tu rúbrica.
3. Desarrolla el procedimiento o argumento y registra evidencia.
4. Añade fuentes verificadas por ti.
5. Revisa manualmente y exporta respaldo JSON.

Datos en este navegador. No hay sincronización, conexión institucional, analítica ni dependencias externas. Las búsquedas abren sitios externos y comparten allí el texto de consulta. No contienen integración con API ni descarga automática.

## Desarrollo
Sin compilación ni instalación de dependencias. Sirve la raíz con un servidor estático; por ejemplo `python -m http.server 8080`, solo para desarrollo. Abre `http://localhost:8080`.

Pruebas con Node.js moderno: `node --test` o `npm test`. Los visitantes abren GitHub Pages sin estos programas.

# Publicación

Repositorio público `REKOL08/aula-consultas-multidisciplinares`. GitHub Pages sirve rama `main`, raíz `/`. `.nojekyll` desactiva Jekyll. No hay compilación, secretos ni backend. Todos los assets son relativos a la carpeta del proyecto.

URL: https://rekol08.github.io/aula-consultas-multidisciplinares/

Antes de actualizar: `node --test`, revisar cambios, commit y push. Consultar Settings → Pages y Actions; verificar despliegue aprobado y respuesta HTTP 200. Un push no acredita publicación. Referencia oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Para un fork: habilitar Pages en main/raíz y ajustar los enlaces absolutos al repositorio y al portal según la cuenta nueva. Los archivos de aplicación permanecen autónomos. Los visitantes solo abren el enlace; las herramientas de desarrollo son opcionales para mantenedores.

# Pruebas

Ejecutar `node --test` en la raíz con Node.js moderno. No requiere instalar paquetes. Se cubren rutas de todas las áreas, diferencias por disciplina, claves desconocidas, esquema estricto de respaldos, duplicados, límites de texto, URLs inseguras, codificación de búsquedas y progreso manual.

Resultado inicial: 7 pruebas aprobadas y comprobación de sintaxis `node --check app.js` aprobada.

Revisión manual recomendada: cargar ejemplo, cambiar disciplina, editar consigna/desarrollo, añadir y eliminar fuente, marcar revisión, recargar y verificar guardado, exportar/importar, cancelar reemplazos, intentar JSON inválido, bloquear localStorage, revisar teclado y pantalla estrecha. Las pruebas puras no equivalen a comprobar interacción visual en todos los navegadores.

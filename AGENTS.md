# Agente Aula · metodología y fuentes multidisciplinares

Especialidad: convertir consignas académicas en procesos claros, documentar evidencias y favorecer revisión crítica entre disciplinas.

## Responsabilidad
Mantén solo este proyecto. Prioriza rutas honestas, pocos pasos, acceso móvil y teclado, y bajo consumo de recursos. No presentes plantillas como IA, respuestas correctas o validación experta. No asumas una única metodología ni un reglamento colombiano universal.

## Proceso
1. Lee README y docs antes de editar.
2. Conserva las advertencias visibles sobre alcance y revisión manual.
3. No añadas CDN, frameworks, telemetría, claves, backend o servicios de pago sin solicitud explícita.
4. Valida importaciones y conserva protocolos http(s) para fuentes.
5. Ejecuta `node --test` y verifica rutas de assets bajo la carpeta Pages.
6. Revisa interfaz móvil y teclado cuando la infraestructura lo permita; informa límites reales.
7. Actualiza documentación antes de publicar y confirma estado Pages.
8. No publiques datos de estudiantes ni respaldos privados.

Este archivo personaliza instrucciones para agentes de desarrollo. No inicia un agente permanente en GitHub Pages. Pages sirve archivos estáticos.
